# Decisões técnicas

Cada decisão técnica deve registrar:

- Contexto
- Alternativas consideradas
- Motivo da decisão
- Benefícios obtidos

## Por que Angular?

Angular foi escolhido por oferecer uma estrutura completa para aplicações web com formulários reativos, serviços HTTP, componentização e build de produção.

## Por que ASP.NET Core?

ASP.NET Core foi escolhido por ser uma plataforma moderna para APIs, com boa integração com C#, Entity Framework Core, autenticação e testes.

## Por que SQL Server?

SQL Server foi escolhido por combinar bem com Entity Framework Core e com o ecossistema .NET.

## Por que JWT?

JWT permite autenticar requisições HTTP de forma stateless e integrar frontend e backend com simplicidade.

## Por que arquitetura em camadas?

A arquitetura em camadas separa responsabilidades e facilita manutenção, testes e evolução do projeto.

## Por que services diretos?

Services diretos e DTOs simples mantêm o MVP legível. Abstrações novas só devem entrar quando houver repetição real ou ganho claro.

## Por que `.slnx`?

O projeto usa o formato `.slnx` para manter a solução .NET alinhada com a preferência atual do repositório.
