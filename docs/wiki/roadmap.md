# Roadmap

## Concluído

- Backend em ASP.NET Core Web API
- Arquitetura em camadas
- Modelagem de domínio
- Entity Framework Core
- Autenticação JWT
- Frontend Angular
- Testes automatizados
- CI com GitHub Actions
- Docker Compose local
- Health checks
- Cadastro e login
- Perfil editável
- Alteração de senha
- Bloqueio de login por tentativas inválidas
- Reset admin de senha para usuários bloqueados
- Status do sistema
- Preferências locais
- Contas financeiras
- Categorias
- Lançamentos
- Filtros de lançamentos
- Dashboard mensal
- Gráfico de fluxo de caixa com dados reais
- Exportação CSV
- Edição de contas
- Edição de categorias
- Exclusão de lançamentos
- Bloqueio de exclusão de contas e categorias com lançamentos vinculados
- Saldo atual considerando saldos iniciais por data de início

## Em Desenvolvimento
