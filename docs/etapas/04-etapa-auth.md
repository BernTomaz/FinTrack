# 04 - Auth

## Objetivo

Permitir cadastro, login e proteção dos dados do usuário.

## Tarefas

- Cadastro de usuário
- Login
- Hash de senha
- Emissão de JWT
- Identificação do usuário logado
- Proteção dos endpoints privados

## Endpoints

```text
POST /auth/register
POST /auth/login
GET /auth/me
```

## Status

Concluída no backend.
