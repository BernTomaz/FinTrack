# 08 - Frontend Angular

## Objetivo

Criar a interface web do MVP.

## Telas

- Login
- Cadastro
- Dashboard
- Contas
- Categorias
- Lançamentos

## Fluxo

Usuário entra, faz login, acessa dashboard e gerencia suas informacoes financeiras.

## Decisão de Interface

Começar com Angular simples, Reactive Forms e HttpClient. Biblioteca visual só entra se realmente acelerar o MVP.

O layout é responsivo, com telas principais confortáveis no mobile.

## Status

Primeira versão funcional concluída.

## Implementado

- Login
- Cadastro
- Dashboard mensal
- Contas
- Categorias
- Lançamentos
- Exportação CSV
- Layout responsivo inicial
