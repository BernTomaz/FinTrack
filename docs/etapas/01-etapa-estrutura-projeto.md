# 01 - Estrutura do Projeto

## Objetivo

Criar a base técnica do projeto sem implementar regra de negócio ainda.

## Tarefas

- Criar solução `FinTrack.slnx`
- Criar projetos backend
- Criar projeto Angular
- Referenciar projetos .NET
- Configurar Swagger
- Configurar arquivos base de ambiente
- Preparar Docker Compose

## Estrutura Esperada

```text
src/
  FinTrack.Api/
  FinTrack.Application/
  FinTrack.Domain/
  FinTrack.Infrastructure/
  FinTrack.Web/
tests/
  FinTrack.Tests/
```

## Decisão

Usar `.slnx` como arquivo de solução do .NET.
