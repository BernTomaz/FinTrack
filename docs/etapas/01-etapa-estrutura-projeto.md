# 01 - Estrutura do Projeto

## Objetivo

Criar a base tecnica do projeto sem implementar regra de negocio ainda.

## Tarefas

- Criar solution `FinTrack.slnx`
- Criar projetos backend
- Criar projeto Angular
- Referenciar projetos .NET
- Configurar Swagger
- Configurar arquivos base de ambiente
- Preparar Docker Compose

## Estrutura Esperada

```text
src/
  FinTrack.Api/
  FinTrack.Application/
  FinTrack.Domain/
  FinTrack.Infrastructure/
  FinTrack.Web/
tests/
  FinTrack.Tests/
```

## Decisao

Usar `.slnx` como arquivo de solution do .NET.
