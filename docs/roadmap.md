# Roadmap

## Agora

- Confirmar no GitHub o CI atualizado com SQL Server e fluxo no navegador.
- Revisar os alertas das dependências existentes do frontend antes do deploy.
- Revisar deploy público.

## MVP concluído

- Usuários
- Login
- Contas
- Categorias
- Lançamentos
- Dashboard mensal
- Gráfico de fluxo de caixa com dados reais
- Exportação CSV
- Exclusão de lançamentos
- Bloqueio de exclusão de contas e categorias com lançamentos vinculados
- Saldo atual com saldos iniciais das contas
- Perfil editável
- Alteração de senha
- Testes principais
- CI de backend e frontend

## Depois do MVP

- Deploy público.
- Melhorias visuais.
- Relatórios adicionais.
- Backup e restauração.

## Pós-MVP concluído

- Edição de contas.
- Edição de categorias.
- Paginação dos relatórios com filtros e ordenação no servidor.
- SQL Server e validação de navegador configurados no CI.
- Revisão de CSS e documentação em 20/10/2026.

## Fora do MVP

- Integração bancária.
- IA.
- OCR.
- App mobile.
- Multi-moeda.
- Assinatura paga.
