# Checklist de Deploy

Deploy fica fora do primeiro passo, mas o projeto deve se preparar para isso.

## Antes de Publicar

- Configurar variáveis de ambiente
- Usar chave JWT forte
- Conferir connection string
- Rodar migrations
- Rodar testes
- Validar frontend em build de produção
- Conferir CORS
- Conferir HTTPS
