# Roadmap de Implementação

- Criar solução `FinTrack.slnx`
- Criar projetos
- Configurar referências
- Configurar Swagger

## 2. Domínio e Banco

- Criar entidades e enums
- Criar DbContext
- Criar migration inicial
- Subir SQL Server local

## 3. Auth

- Cadastro
- Login
- JWT
- Usuário logado

## 4. Financeiro

- Contas
- Categorias
- Lançamentos
- Filtros

## 5. Resumo

- Dashboard mensal
- Exportação CSV

## 6. Frontend

- Login e cadastro
- Dashboard
- CRUDs
- Filtros
- Responsividade mobile-first

## 7. Fechamento

- Testes principais
- README final
- README do frontend
- CI de backend e frontend
- Docker Compose validado

- Gráfico de fluxo de caixa com dados reais.
- Exclusão de lançamentos pela interface.
- Bloqueio de exclusão de contas e categorias com lançamentos vinculados.
- Mensagens de erro temporárias com saída suave.
- Documentação final de status, endpoints, testes e fluxos.
